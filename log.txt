# Project Log - Planetary Micro-Rover

## Project Description (Current Hybrid Design)

Dual-Spectrum Planetary Micro-Rover using an MSP432P401R (ARM Cortex-M4F) for actuator control and an ESP32 DevKit for sensor processing + WiFi dashboard. The MSP432 handles 2-wheel differential drive (motors + encoders) and pan/tilt servo sweep for 3D scanning. The ESP32 reads the VL53L1X ToF sensor via I2C (Adafruit library), receives servo position from MSP432 via UART, and broadcasts combined 3D scan data over WiFi WebSocket to a browser dashboard.

### Split Architecture
- **MSP432 (CCS, single .c file):** Motor PWM + encoder odometry + servo PWM (pan/tilt). Sends position data via UART to ESP32. No I2C/ToF on MSP432.
- **ESP32 (Arduino IDE):** VL53L1X ToF via Adafruit library, WiFi AP "ROVER3D", HTTP dashboard + WebSocket server. Receives MSP432 UART data, reads ToF, serves combined visualization.

### Servo PWM Configuration

- **Timer:** TimerA0, UP mode
- **Clock:** SMCLK=12MHz, prescaler /16 → 750kHz
- **Period:** 15000 ticks → 20ms (50Hz)
- **Pulse mapping:** 0deg = 750 ticks (1ms), 180deg = 1500 ticks (2ms)
- **Output mode:** TIMER_A_OUTPUTMODE_RESET_SET

#### Servo Ranges
- **Pan (P2.6/TA0.3):** 0 to 90 degrees
- **Tilt (P2.7/TA0.4):** 37 to 180 degrees
- **Sweep step:** 2 degrees
- **Movement speed:** 30ms per degree step (smooth), 50ms settle at each position

### System Clock
- MSP432: 12MHz DCO (`CS_setDCOCenteredFrequency(CS_DCO_FREQUENCY_12)`)
- ESP32: Default 240MHz (Arduino handles this)

## Communication Protocol

### MSP432 → ESP32 (UART, 115200 baud)

| Format | Description |
|--------|-------------|
| `P,pan,tilt\r\n` | Servo position update (pan=0-90, tilt=37-180) |
| `START\r\n` | Scan begin |
| `DONE\r\n` | Scan complete |

### ESP32 → WebSocket → Browser

| Format | Description |
|--------|-------------|
| `D,dist,status\r\n` | ToF distance in mm, 1=valid 0=wait |
| `S,pan,tilt,dist\r\n` | 3D scan point with position + distance |

## Key Code Lessons (MSP432/CCS)

### CCS Constraints
- Single .c file only (multifile headersstruggle with CCS)
- C89 mode: declare all variables at top of block, no in-loop declarations
- DriverLib functions are reliable; use them

### Clock
- **Working:** `CS_setDCOCenteredFrequency(CS_DCO_FREQUENCY_12)`
- Don't use 48MHz crystal setup

### UART Config (115200 @ 12MHz SMCLK)
```c
const eUSCI_UART_Config uart = {
    EUSCI_A_UART_CLOCKSOURCE_SMCLK,
    6, 8, 32,                         // BRDIV, UCxBRF, UCxBRS
    EUSCI_A_UART_NO_PARITY,
    EUSCI_A_UART_LSB_FIRST,
    EUSCI_A_UART_ONE_STOP_BIT,
    EUSCI_A_UART_MODE,
    EUSCI_A_UART_OVERSAMPLING_BAUDRATE_GENERATION
};
```
- Don't use `eUSCI_UART_ConfigV1` (undefined in older DriverLib)
- Don't use `EUSCI_A_UART_8_BIT_LEN` (undefined)

### Register Access (CRITICAL - struct style, not MSP430 macros)
- **Don't use:** `UCA0IFG`, `UCTXIFG`, `UCB0CTLW0`, `UCTXSTT`, `UCBBUSY` — NOT defined in MSP432 CCS headers
- **Must use struct-based:**
  - `EUSCI_A0->IFG & EUSCI_A_IFG_TXIFG`
  - `EUSCI_B0->CTLW0 |= EUSCI_B_CTLW0_TR | EUSCI_B_CTLW0_TXSTT`
  - `EUSCI_B0->STATW & EUSCI_B_STATW_BBUSY`
  - `EUSCI_B0->IFG & EUSCI_B_IFG_NACKIFG`

### Delay (no SysTick dependency)
```c
void delay_ms(uint32_t ms) {
    uint32_t i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 3000; j++)
            __no_operation();
}
```
- Don't use SysTick-based delay (vector table / interrupt setup not guaranteed in CCS)

### LED
- P1.0 always add LED blink to verify code executes before debugging peripherals

## Key ESP32 Notes

- **VL53L1X Library:** Use Adafruit_VL53L1X (Arduino Library Manager). Works reliably. Avoid raw I2C register access on ESP32.
- **XSHUT:** Must toggle LOW for 50ms then HIGH for 50ms before `vl53.begin()`
- **I2C pins:** GPIO21 (SDA), GPIO22 (SCL) at 100kHz
- **UART from MSP432:** GPIO16 at 115200 baud

## Motor Notes (RSLK Chassis - for future use)

### Pin Mapping
| Function | Pin |
|----------|-----|
| Left DIR | P3.7 |
| Left SLP | P3.6 |
| Right DIR | P3.5 |
| Right SLP | P3.0 |
| Left PWM | P2.4 (TA0.1) |
| Right PWM | P2.5 (TA0.2) |

### Control
- SLP HIGH = awake, LOW = sleep
- DIR LOW = forward, HIGH = backward
- Must wake motors (SLP HIGH) before PWM works

### Calibration
- Right motor 0.96 ratio (multiply right PWM by 0.96)
- Speed: ~0.038 cm/ms at PWM 128
